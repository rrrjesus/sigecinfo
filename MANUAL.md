# Manual de Utilização do SIGECINFO

## Introdução

Bem-vindo ao **SIGECINFO (Sistema de Gerenciamento e Controle de Informações)**. Este manual tem como objetivo orientar os usuários na utilização das funcionalidades do sistema, desde as operações mais básicas até as mais avançadas.

O SIGECINFO é uma aplicação web projetada para facilitar o gerenciamento de eventos, controle de acesso de pessoas e geração de relatórios, centralizando as informações de forma segura e eficiente.

## Estrutura do Manual

Este manual está organizado de acordo com as principais funcionalidades do sistema:

1.  **Visão Geral e Acesso**
2.  **Gestão de Eventos**
3.  **Controle de Acesso (QR Code)**
4.  **Relatórios**
5.  **Autenticação e Perfil de Usuário**

---

## 1. Visão Geral e Acesso

Para acessar o sistema, utilize a tela de login informando seu e-mail e senha. Caso tenha esquecido sua senha, há uma opção para recuperá-la. O sistema também permite o acesso rápido utilizando sua conta do Google.

![Tela de Login](https://via.placeholder.com/600x400.png?text=Tela+de+Login)

Após o login, você será direcionado ao painel principal, onde terá uma visão geral dos próximos eventos e acesso rápido às principais funcionalidades.
